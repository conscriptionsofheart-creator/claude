# Lesson draft: Greet a guest with a template

Draft only. Not voiced and not registered in the app. It waits until the menus settle.
Scripts never run until you turn them on.

## Steps (the exact taps, in order)

1. Open the Scripts tab.
2. Find Blocks. Press the template Greeting at the door. A trigger box called Doorway appears. It is not armed.
3. Look at the code box. It starts with "Made from blocks" and reads like a short story.
4. On the Beat strip, record a short greeting and name the range Greeting.
5. Change the wait in the rule if it has one, or press Template: Fall and get up to see one with a wait.
6. Turn Scripts on. Turn Gizmos live on.
7. Press Test it with me. A pretend guest walks in. The greeting plays, and the log says which block ran.
8. Edit one word in the code box. The blocks turn grey and say Edited as code. That is on purpose.
9. Turn Scripts off. Everything stops and goes back.

## What to try
Use the template Doorbell, and give another object a script that hears the event doorbell.
