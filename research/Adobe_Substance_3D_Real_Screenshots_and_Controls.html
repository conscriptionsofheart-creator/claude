04 · Interaction mechanics alongside the screenshots

This table explains what the photographed/diagrammed panels do while sculpting. It is based primarily on Adobe’s VR shortcuts, tools and desktop shortcuts help pages, with uncertain version-specific mappings identified below.

VR interaction and controllers

Tool trigger (TT)Act with the active sculpting tool or pointer. Hold for a continuous stroke.
Support bottom button (S2)Hold to bring up the floating Palette; tool hand then points to buttons/sliders and TT confirms.
Support top button (S1)Switch the VR brush placement mode, commonly between Free and Gizmo placement.
Either grip (SG or TG)Grip-and-drag the world relative to your body, including seated work.
Both grips togetherMove the controllers apart/together to rescale the world between miniature and immersive sizes.
Support thumbstick left / rightUndo / redo in normal mode.
Support thumbstick up / downScope deeper into hovered content / out to its parent.
Tool thumbstick up / downResize brush in Adobe’s current controller shortcut guide; note a conflicting older brush-help mapping.
Tool thumbstick left / rightAdjust hardness when the current brush supports hardness.
Tool top button (T1)Brush Quicktune when sculpting; select hovered object in selection contexts.
Tool bottom button (T2)Quick-swap compatible sculpting tools; context-sensitive selection and deletion operations with Select.
Support trigger (ST)Modifier for object duplication, brush repositioning or alternate smooth behavior according to active tool and context.
Support stick clickEnter color-pick mode, then choose the scene color with TT.
S2 + tool stick left / rightExpand Palette or contextual Actions menu.
S2 + support stick up / downMinimize or maximize the Palette and Actions panels.

Making a shape

Desktop: Choose Clay, Erase, Warp, Buildup or another tool in the Palette. Position the Gizmo or surface brush; click/drag, or apply a Gizmo-stationary brush with Space. Use brush parameter controls for size, pressure, shape and stroke smoothing.

VR: Select the same tool from the support-hand Palette. Position the tool controller in physical 3D space and squeeze TT to deposit or shape clay. Continue holding the trigger while tracing a path to make a stroke. Trigger pressure can change strength when enabled.

Manipulating world vs object

World: Either grip moves the whole scene relative to your body. Two grips together scale the scene, allowing a miniature world or room-scale sculpt.

Objects: Select and manipulate objects separately. In VR, free-placement grabbing can move an object directly, while Gizmo placement supports axis/rotation handles. Selected objects can be duplicated, grouped and scoped.

Documented inconsistency: Adobe’s VR controller reference maps brush size to the tool-hand thumbstick (TJ up/down). A separate older brush-help article assigns brush scaling to the support thumbstick (SJ up/down). Use the controller map and in-headset contextual tooltips for the installed version, rather than assuming both descriptions remain current. Adobe also has context-specific mappings for S2, T2 and the support trigger.

Painter: texture and UV work

The interface centers on the 3D model alongside a 2D UV view. The layer stack, brush controls, texture sets, shader properties and asset shelf support material painting. Alt-modified mouse drags orbit, pan and zoom.

Designer: material graphs

Nodes and wires are the primary manipulation system. Dockable Explorer, Library, Properties, 2D and 3D previews surround the graph. It is not a VR sculpting application.

Sampler: input/filter layering

Images, filters and material layers form a stack. The 3D preview and channel outputs change as the selected filter properties are adjusted.

Stager: scene composition

The central 3D viewport supports object placement, camera composition, lighting, stage assets, properties and render controls. It resembles a digital product photography stage more than a digital sculpting canvas.
